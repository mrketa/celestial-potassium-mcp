# Potassium MCP Bridge

This repository is a standalone local MCP bridge for bounded Roblox inspection. Preserve Protocol 2 mutual authentication, loopback-only transport, FIFO single-flight ownership, bounded/redacted read-only tools, and the configured artifact/trace/HTTPS allowlists.

Gameplay automation is intentionally not included. Do not add collectors, movement, teleports, remotes, input actions, rewards, runtime controls, arbitrary code execution, arbitrary filesystem access, source/bytecode access, or hooks. Deployment owns only the canonical bootstrap and autoexec scripts.
