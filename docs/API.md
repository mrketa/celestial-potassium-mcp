# API

The public MCP surface provides bridge status/capabilities and bounded read-only Roblox inspection: client state, instance/class/property/tag inventories, ancestry, snapshots, spatial queries, logs, performance, and public metadata. It also reads configured artifacts, traces, and HTTPS hosts within their explicit bounds.

All outputs are size-bounded and redacted where needed. There are no tools for gameplay automation, arbitrary code, arbitrary files, source, bytecode, remotes, input, teleports, or hooks.
