# Agent-assisted installation

Give the prompt below to a trusted local coding agent that can run PowerShell and edit your MCP client configuration. The agent must not claim success until it completes the live checks. Installation is Windows-only and requires Potassium as executor.

> In the OMP project whose `.omp\mcp.json` should be configured, verify Windows and Node.js 22+, then run `npx --yes @mrketa/potassium-mcp@beta install`. Do not use a repository checkout, a PowerShell setup script, GitHub Packages, or a token. Confirm the default workspace is `%LOCALAPPDATA%\Potassium\workspace` unless I provide a verified alternative. Run `npx --yes @mrketa/potassium-mcp@beta doctor --json`; do not suppress failures or disclose the token. Confirm only `mcpServers.potassium` was merged into the active project configuration and that its launcher uses the stable server path, `--config`, and a 30000 ms timeout. Ask me to restart or reload the MCP host first and then restart Potassium. If authentication or deployment checks fail, run `repair`; never weaken ACLs or manually copy a token.
